DiagnosticLogger

Detailed, replay-oriented execution and HTTP diagnostics.

Authorization values are intentionally never persisted. Each HTTP request gets a directory containing request/response metadata, a replayable curl command, JSON bodies when present, and decoded InlineBase64 definition parts.
